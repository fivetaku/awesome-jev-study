# 이 스터디를 읽는 법

[한국어](../ko/how-to-read.md) · [English](../en/how-to-read.md)

awesome-jev는 CC0 큐레이션 목록이고 여기에는 `22570dcd`에 고정되어 있다. 비공식이다 (README.md:20). 이 저장소는 그 목록을 읽은 것이다. 목록의 두 번째 사본이 아니고 링크된 소스를 검사한 기록도 아니다.

언어는 한국어와 영어다. Go, Rust, 그 밖의 클라이언트 언어로 포팅한 것이 아니다. 그 클라이언트는 SDK 절에 페이지가 있고 페이지는 목록이나 GitHub API가 준 언어를 적는다.

표시:

- 목록 문장. CC0 한 줄. 인용한다.
- 문서. 2026-09-22에 받아 온 공식 페이지에 있던 문장.
- 실행. 그날의 GitHub API 필드나 curl.
- 미확인. 목록은 말하는데 조회에서 보이지 않은 것. $40M이 이 칸이다.
- 추론. 모든 프로젝트 페이지의 LLM 절과 스크립트 절.

대표 표의 저자 보고 비용, 지연, 스타 문구는 재측정하지 않았다.

링크된 코드는 자기 라이선스를 유지한다. AGPL 자료는 설명만 하고 복사하지 않는다.
