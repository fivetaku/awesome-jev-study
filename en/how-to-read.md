# How to read this study

[한국어](../ko/how-to-read.md) · [English](../en/how-to-read.md)

awesome-jev is a curated list, CC0, pinned here at `22570dcd`. It is unofficial (README.md:20). This repository is a reading of that list. It is not a second copy of the list, and it is not an audit of the linked source trees.

Two languages, Korean and English. Not a port into Go, Rust, or the other client languages. Those clients each have a page under SDKs, and the page names the language the list or the GitHub API gave.

Labels:

- List sentence. The CC0 line. Quoted.
- Doc. A sentence that was on an official page fetched 2026-09-22.
- Run. A GitHub API field or a curl from that day.
- Unverified. The list says it and the fetch did not show it. The $40M figure is in this bucket.
- Inference. The LLM section and the script section on every project page.

Author-reported cost, latency, and star slogans in the featured table were not remeasured.

Linked code keeps its own license. AGPL material is described and not copied.
