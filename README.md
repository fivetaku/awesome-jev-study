# awesome-jev-study

[한국어](README.ko.md) · [English](README.md)

A reading of [kraayenjon/awesome-jev](https://github.com/kraayenjon/awesome-jev) at `22570dcd`, in Korean and English.

The list is a curated catalog of Jev, TypeSafe's System One model. This repository says what Jev is, what role the list assigns Jev in each row, what the list sentence and a 2026-09-22 page front show about setup, and how that job would differ with an LLM or with a script. The last two are inference. They were not run.

This is not a source audit. Linked repositories were not cloned for this study. Where a README front does not show an endpoint, a key, or a question schema, the page says so instead of inventing one.

The featured table's costs and latencies are author-reported (list README.md:209). They were not remeasured. The FAQ's $40M funding figure was not in the launch post fetched that day. It stays unverified.

CC0 on the list does not license the linked code. usenotra/notra is AGPL-3.0 and is described only.
